    Definition 2.2.1. Quadratic Regression.

    A quadratic regression is a regression which fits real-life data to a quadratic function.
    🔗
    🔗

    Note 2.2.2.

    Finding a quadratic regression is like finding a linear regression, except that you select Quadratic Regression in Desmos instead of Linear Regression.
    🔗
    🔗
