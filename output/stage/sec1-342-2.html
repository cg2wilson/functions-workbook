    Section 1.4 Section 1.3/1.4/2.2

    Definition 1.4.1. Linear Function.

    A linear function is a function which can be written in the form
    \begin{gather*} f(x) = ax + b \end{gather*}
    where \(a\) and \(b\) are constants.
    🔗
    🔗

    Definition 1.4.2. Intercepts.

    An intercept is the location where a function crosses an axis.
    🔗
    An \(x-\)intercept is an input where the function crosses the \(x-\)axis, and a \(y-\)intercept is an output where the function crosses the \(y-\)axis.
    🔗
    🔗

    Note 1.4.3.

    Because \(x-\)intercepts occur when a function crosses the \(x-\)axis, this means that all outputs are zero. In particular, this means that all \(x-\)intercepts are solutions to the equation \(f(x) = 0\text{.}\)
    🔗
    Similarly, the \(y-\)intercept occurs at \(y = f(0)\) because the input is 0 along the \(y-\)axis. A function can only have one \(y-\)intercept by definition of a function (see Definition 1.1.2).
    🔗
    🔗

    Definition 1.4.4. Slope.

    The slope of a linear function is defined as the ratio of vertical change to horizontal change. This can be understood to be "rise over run" of the function.
    🔗
    The slope of a linear equation \(y = ax + b\) is the value of the constant \(a\text{.}\)
    🔗
    Given two points \((x_1,y_1)\) and \((x_2,y_2)\text{,}\) the slope of the line between the two points is given by
    \begin{gather*} a = \dfrac{y_2-y_1}{x_2-x_1} \end{gather*}
    🔗
    🔗

    Definition 1.4.5. Constant Rate of Change.

    The constant rate of change of a linear function is the value of its slope.
    🔗
    The units of a rate of change are always output per input
    🔗
    🔗

    Example 1.4.6.

    Consider the equation \(2x + 5y = 8\text{.}\) It is linear because we can isolate \(y\) and write the equation in the form \(y = ax + b\text{;}\) rewriting gives
    \begin{gather*} y = -\dfrac{2}{5}x + \dfrac{8}{5} \end{gather*}
    🔗
    If we want to find the \(x-\)intercept, we can do so by setting \(y = f(x) = 0\text{.}\) This gives:
    \begin{align*} 0 \amp = -\dfrac{2}{5}x + \dfrac{8}{5}\\ \dfrac{2}{5}x \amp = \dfrac{8}{5} \\ x \amp = 4 \end{align*}
    So the \(x-\)intercept occurs at \((4,0)\text{.}\)
    🔗
    For the \(y-\)intercept, we need to find \(f(0)\text{.}\) This means we plug in 0 to the equation:
    \begin{gather*} f(0) = -\dfrac{2}{5}(0) + \dfrac{8}{5} = \dfrac{8}{5} \end{gather*}
    🔗
    Since the slope is the value of the constant \(a\) when the equation is in the form \(y = ax + b\text{,}\) and we know that \(y = -\dfrac{2}{5}x + \dfrac{8}{5}\text{,}\) the slope is \(a = -\dfrac{2}{5}\text{.}\) This tells us that when creating the line, to move from one point to another, we must go down two units and right five units.
    🔗
    🔗

    Example 1.4.7.

    Assume that the function \(M(x) = 0.137x + 11.068\) gives the number of animals (in thousands) in a federally protected marine zone, \(x\) years since the zone was established.
    🔗
    This function is linear because it can be written in the form \(y = ax + b\text{;}\) here, \(y = M(x)\text{,}\) \(a = 0.137\text{,}\) and \(b = 11.068\text{.}\)
    🔗
    The \(x-\)intercept is at \(x = -80.789\) (rounding to three decimal places), and the \(y-\)intercept is at \(y = 11.068\text{.}\)
    🔗
    The slope is \(a = 0.137\text{,}\) which tells us that the number of animals increases by 0.137 thousand animals per year.
    🔗
    🔗

    Definition 1.4.9. Cost, Revenue, and Profit.

    Total cost of a product is composed of two parts: fixed and variable costs. Fixed costs are those which remain constant regardless of the number of units produced. Variable costs are those directly related to the number of units produced.
    🔗
    Revenue is the total amount of money earned, generally found by multiplying the price per unit times the number of units.
    🔗
    Profit is the amount of money earned after accounting for cost. Profit can be written as
    \begin{gather*} P(x) = R(x) - C(x) \end{gather*}
    where \(P(x)\) is profit from the production of \(x\) units, \(R(x)\) is the revenue from the production of \(x\) units, and \(C(x)\) is the cost from the production of \(x\) units.
    🔗
    🔗

    Example 1.4.10.

    Suppose that a company manufactures 50-inch QLED TVs and sells them for $700. The costs incurred in the production and sale of the TVs are $100,000 plus $500 for each TV produced and sold.
    🔗
    The total cost is the sum of variable and fixed costs. The production costs $100,000 independent of the number of units produced, so this is our fixed cost. The variable cost adds $500 for each TV produced; this means that
    \begin{gather*} C(x) = 100000 + 500x \end{gather*}
    where \(x\) is the number of units produced.
    🔗
    The revenue is the amount of money made from the sale of \(x\) TVs. Since each TV is sold for $700, the revenue is given by
    \begin{gather*} R(x) = 700x \end{gather*}
    🔗
    This means that the profit is given by
    \begin{align*} P(x) \amp = R(x) - C(x)\\ P(x) \amp = 700x - (500x + 100000) \\ P(x) \amp = 200x - 100000 \end{align*}
    So the profit function is given by \(P(x) = 200x - 100000\) dollars when \(x\) units are sold.
    🔗
    🔗

    Check Your Understanding 1.4.11.

    🔗
    Answer.
    \(P(x) = 58x \)

    Forms of Lines.

    The slope-intercept form of a line is written as
    \begin{gather*} y = ax + b \end{gather*}
    where \(a\) is the slope of the line and \(b\) is the output value of the \(y-\)intercept. In particular, the \(y-\)intercept is located at the point \((0,b)\text{.}\)
    🔗
    The point-slope form a line is written as
    \begin{gather*} y - y_1 = a(x - x_1) \end{gather*}
    where the line passes through the point \((x_1,y_1)\) with slope \(a\text{.}\)
    🔗
    🔗

    Example 1.4.12.

    A line passes through the points \((7,2)\) and \((-1, -4)\text{.}\) We will find the slope-intercept and point-slope forms of the lines.
    🔗
    To find the slope-intercept form, we first need to find the slope. Recall from Definition 1.4.4 that we can use the two points to find the slope:
    \begin{align*} a \amp = \dfrac{y_2 - y_1}{x_2 - x_1} \\ \amp = \dfrac{2 - (-4)}{7 - (-1)} \\ \amp = \dfrac{6}{8} \\ \amp = \dfrac{3}{4} \end{align*}
    Now that we have the slope, we can find the \(y-\)intercept by using the slope-intercept form of the line:
    \begin{align*} y \amp = ax + b \\ y \amp = \dfrac{3}{4}x + b \end{align*}
    At this point, we need to input one of the points into \(x\) and \(y\text{.}\) We can choose either one; let’s pick the first one because both numbers are positive. This means we have
    \begin{align*} y \amp = \dfrac{3}{4}x + b \\ 2 \amp = \dfrac{3}{4}(7) + b\\ 2 \amp = \dfrac{21}{4} + b \\ \dfrac{8}{4} \amp = \dfrac{21}{4} + b \\ -\dfrac{13}{4} \amp = b \end{align*}
    So, our slope-intercept form of the line is given by
    \begin{gather*} y = \dfrac{3}{4}x - \dfrac{13}{4} \end{gather*}
    🔗
    Now that we have the slope, we can write the point-slope equation without too much trouble. Let’s again pick the point \((7,2)\) to use:
    \begin{align*} y - y_1 \amp = a(x-x_1)\\ y - 2 \amp = \dfrac{3}{4} (x - 7) \end{align*}
    🔗
    🔗

    Note 1.4.13.

    We can recover the slope-intercept form of the line from the point-slope form. We found that the point-slope form of the line given in Example 1.4.12 was given by
    \begin{align*} y - 2 \amp = \dfrac{3}{4} (x - 7) \end{align*}
    Distributing the slope gives
    \begin{align*} y - 2\amp = \dfrac{3}{4}x - \dfrac{21}{4} \end{align*}
    and moving the 2 to the other side gives
    \begin{align*} y \amp = \dfrac{3}{4}x - \dfrac{13}{4} \end{align*}
    which is precisely the slope-intercept form of the line we found earlier.
    🔗
    🔗

    Check Your Understanding 1.4.14.

    Definition 1.4.15. Average Rate of Change.

    The average rate of change of a function is the constant rate at which a function should change in order to move from one point to another.
    🔗
    🔗

    Note 1.4.16.

    The average rate of change of a function is exactly the slope of the line between the two points in question.
    🔗
    🔗

    Example 1.4.17.

    The average rate of change of the function \(f(x) = 2x^2 + 3x - 1\) between \((0,-1)\) and \((2,13)\) is given by
    \begin{align*} a \amp = \dfrac{y_2 - y_1}{x_2 - x_1} \\ \amp = \dfrac{13 - (-1)}{2-0} \\ \amp = \dfrac{14}{2} \\ \amp = 7 \end{align*}
    We have two interpretations of this number.
    🔗
    The first interpretation is that the slope of the line between the points \((0,-1)\) and \((2,13)\) is exactly \(7\text{.}\) We can see this in the image below.
    🔗
    The second interpretation is to say that if we were to travel at a constant rate of change between \((0,-1)\) and \((2,13)\text{,}\) we would have to travel \(7\) outputs units per input unit.
    🔗
    🔗

    Definition 1.4.19. Linear Regression.

    A regression is a function which approximates the behavior of real-life data.
    🔗
    A linear regression is a regression on data points which appear to be line-like. A linear regression is often called a line of best fit
    🔗
    🔗
